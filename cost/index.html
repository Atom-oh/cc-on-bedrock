비용 관리

대규모 사용자 환경에서도 효율적으로 예산을 관리할 수 있는 도구.

1. EC2-per-user DevEnv 모드 비용

항목단가 (ap-northeast-2)비고

EBS gp3 root$0.08 / GB·월40 GB 기본 → ~$3.2/월
Hibernation EBS동일 (RAM 덤프 저장 포함)ADR-010

4. 사용량 추적 파이프라인 (ADR-019)

EC2 instance (Instance Profile credentials)
또는 사용자 PC (Local Mode, STS credentials)
  → Bedrock InvokeModel / Converse
  → Bedrock invocation logging (CloudWatch Logs, textData=false)
  → Subscription Filter (IAM role prefix 매칭)
  → bedrock-usage-tracker Lambda
  → cc-on-bedrock-usage DynamoDB (Streams)
  → token-limit-enforcer Lambda (Stream consumer)
  → 한도 초과 시 cc-on-bedrock-limits DENY#active + IAM Deny attach

이전 버전이 사용하던 CloudTrail + EventBridge 방식 대비 정확한 토큰 수까지 추적, textData=false로 CloudWatch Logs 비용 ~99% 절감.

5. 예산 / 한도 제어 (ADR-015)

5.1 USD 예산 budget-check

  • 5분 주기 Lambda
  • 80% 도달 → SNS 경고
  • 100% 도달 → IAM Deny attach
  • 익일 자정 (KST) → limit-reset Lambda가 Deny 자동 해제

5.2 Normalized 토큰 한도 token-limit-enforcer

  • usage table Streams 이벤트마다 normalized_tokens 누적
  • 한도 초과 즉시 DENY#active + IAM Deny attach
  • KST 자정 (daily) / 일요일 (weekly) / 매월 1일 (monthly) reset
두 메커니즘은 독립적이며 어느 한쪽만이라도 트리거되면 사용자 차단.

6. 비용 절감 팁

  • Hibernation 활성화 (ADR-010): ~5초 resume → 사용자가 stop을 꺼리지 않음
  • ec2-idle-stop: CPU/Network 메트릭 기반 자동 stop. EBS는 유지
  • EBS 적정 크기: 40 GB 시작 → user portal에서 확장 신청
  • Local Mode 활용: 본인 PC가 빠른 사용자는 Local로 → EC2 비용 0
  • 모델 가이드: 단순 변환은 Haiku, 복잡한 reasoning은 Opus. /model 픽커 활용
