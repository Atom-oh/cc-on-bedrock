소개

두 가지 배포 모드(EC2 / Local), 주요 특징, 모델 라인업, 8 스택 구조.

아키텍처

8 CDK 스택 매핑(ADR 별), EC2-per-user 아키텍처, Local Mode 흐름, Hybrid AI.

배포 가이드

8단계 CDK/Terraform/CloudFormation 배포, governanceOnly 옵션, 검증 절차.

사용법

EC2 모드 / Local 모드 사용 흐름, /admin/* 페이지 안내, Bedrock 모델 메뉴.

Local 모드

본인 PC + STS + normalized token 한도. 인프라 비용 0. ADR-014.

내 환경

셀프서비스 포털: 환경/스토리지/설정 탭, SSE 프로비저닝, EBS 확장.

비용 관리

EC2/Local 단가표, 모델별 단가, ADR-019 추적 파이프라인, 비용 절감 팁.

보안
