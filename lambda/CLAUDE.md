# Lambda Source Module

Python Lambda handlers. Terraform packages them with `archive_file` from this repo-root directory; they do not live under `terraform/`.
Current truth: `docs/decisions/BASELINE.md` + `docs/architecture.md`.

## Handlers (by decision)
- `user-role-provisioner.py` · `cognito-provisioner-trigger.py` · `role_factory.py` — provisioning and deprovision fan-out (ADR-010, ADR-004).
- `sts-issuer.py` — Local Mode STS issuer: 1h credentials, renewed through `credential_process` (ADR-006). Also returns `mantle {enabled, projectId, region, model}` read from the role's `cc-bedrock-mantle-unmetered` policy (ADR-014 §9).
- `bedrock-usage-tracker.py` · `otel-metrics-rollup.py` / `otel_rollup.py` — usage metering (Inference Profile + Invocation Log → DynamoDB, ADR-005) and the OTel rollup (ADR-009). The tracker also runs every 15 min on `{"source": "cc.mantle-meter"}` (`meter_mantle`) to write display-only `MANTLE#{YYYY-MM}` / `{email}#{date}#{model}` mantle cost estimates from `AWS/BedrockMantle` metrics; nothing that enforces budgets reads that prefix (ADR-014 §9). The rollup parses native Claude Code OTel: `claude_code.*` metrics (S3 `otlp-metrics/`) and scrubbed `tool_result`/`tool_decision` events (S3 `otlp-logs/`) → DynamoDB `USER#email` daily `PROD#`/`SKILL#`/`AGENT#`/`TOOL#`/`ACTIVE#` items, deduplicated per chunk with TTL `OTELOBJ#` markers. Cost and tokens remain owned by ADR-005.
- Session insights (insight only, never enforced; budgets/metering stay on invocation logs, ADR-005): the tracker's `{"source": "cc.session-report"}` branch (`process_session_report`) is invoked synchronously by the dashboard's `POST /api/local/sessions` with `{email, department, subdomain, buckets}`. It re-validates each (tool `claude|codex`, sessionId, UTC date) bucket (≤100, date within 35 days / +1 day, ≤20 models, non-negative int counts; invalid buckets are dropped and counted as `rejected`), prices each model with `estimate_cost` and PutItems (overwrite, cumulative totals) `USER#{email}` / `SESSION#{tool}#{sessionId}#{date}` into `SESSIONS_TABLE_NAME` (`gsiDate` for the sparse `date-index`, TTL 180 days); empty env = feature off. `session-insights.py` runs daily (00:00 UTC) on the previous UTC date (`{"date"}` overrides, `{"force": true}` regenerates; an existing `ok` row is otherwise skipped): reads the date + 7-day baseline from `date-index`, metered per-user cost from a bounded scan of `USER#` / `{date}#` usage rows, computes per-user and fleet stats (cost/turn, cost/session, cache-read ratio, tool/model split, coverage = reported ÷ metered), sends only those numbers with users pseudonymized `U1..U10` to `INSIGHTS_MODEL_ID` via Converse in `INSIGHTS_LANGUAGE`, and writes `INSIGHT#daily` / `{date}` (labels stored, never sent; unparseable output or a Bedrock error → `status: "error"` with the stats kept). Its Bedrock calls are not metered (the invocation-log path only attributes task/local-user roles).
- `budget-check.py` · `token-limit-enforcer.py` · `limit-reset.py` — budget and limit enforcement through IAM deny (ADR-008). `budget-check` enforces per-user daily / weekly / monthly USD caps (`_effective_user_limits`, `evaluate_user_budget`; exceeding any one blocks; UTC windows) plus the department monthly cap. A department row with BOOL `unlimitedPerUser` leaves members without their own cap uncapped, skipping the department per-user default and the global env (ADR-008 amendment 2026-10-29). One-time budget-increase grants (ADR-008 amendment 2026-10-24): the dashboard ADDs flat `grant#{period}#{key}` attributes to the `cc-user-budgets` row (UTC keys `YYYY-MM-DD` / ISO `YYYY-Www` / `YYYY-MM`, cascading daily → weekly + monthly and weekly → monthly; `period_key`, `cascade_targets`, `grant_attr`, mirrored in `shared/nextjs-app/src/lib/budget-grants.ts`). `get_user_budgets` computes `active_grants` once per scan (only keys of the current window count), `_effective_user_limits` adds them only to a capped period (uncapped stays 0), and `write_current_spend` stores them as `activeGrantDaily/Weekly/Monthly`. A new window means a non-matching key, so the cap falls back without any expiry job. token-limit-enforcer periods use KST; its user cap (`_user_cap`) is `max_normalized` plus an approved one-time grant (`grant_normalized`) on `LIMIT#monthly`, counted only for the monthly period when `grant_bucket` is the current KST month. `DENY#active` records `scope` (`user` | `dept`), `period` and the user's `dept` so the dashboard releases only a deny a personal monthly grant cures. `budget-check` also reconciles Codex mantle (`reconcile_mantle`): unlimited-cost users get a per-user us-east-1 mantle project + `cc-bedrock-mantle-unmetered`, everyone else (and everyone on a read failure) loses it; every deny includes `bedrock-mantle:*`/`bedrock-websearch:*` (ADR-014 §9).
  - Upgrade note: a user `monthlyBudget` used to act as a daily cap. It is now month-to-date, and the daily cap comes from `dailyBudget` / dept `perUserDailyBudget` / `DAILY_BUDGET_USD`. Review existing budget rows when upgrading.
- `ec2-idle-stop.py` · `idle-check.py` — idle stop / hibernate schedules (ADR-002); deployed only with `deployment_mode = "devenv"`.
- `nginx-config-gen.py` — per-user nginx routing config from the DynamoDB stream (ADR-003).
- `devenv-session-validator/` — CloudFront viewer-request edge auth (NextAuth JWE; ADR-003/004).
- `audit-logger.py` — CloudTrail Bedrock inference events → `cc-prompt-audit`: one row per call (`{eventTime}#{eventID}` key), `client_tool` claude-code|codex from userAgent, Local + EC2 roles plus account-wide `mode=other`, error events kept, Responses shadow event skipped (ADR-014); bedrock-mantle `CreateInference` (forwarded from us-east-1) recorded with `provider=mantle`, `metered=false`.
- `gateway-manager.py` — supporting handler.
- Codex on Bedrock (ADR-014): `bedrock-usage-tracker.py` normalizes `*.openai.` IDs, prices GPT models with explicit cache rates and writes a `tool` attribute; `token-limit-enforcer.py` weights every model (Claude and GPT) as tracker list price ÷ $15, enforced by tests; `role_factory.py` / `user-role-provisioner.py` grant OpenAI GPT + `project/default`.

## Rules
- Keep sources here; Terraform packages them.
- When a handler change reflects a change in a decision, update the relevant ADR and `BASELINE.md` §3 in the same PR (anti-drift). Handler changes that don't change a decision need no ADR edit.
- `_archived/` and `*-built` artifacts are not active sources.
- Tests: `python3 -m pytest lambda/__tests__ -q` (also run by `tests/run-all.sh`).
