2. EC2-per-user DevEnv

각 사용자에게 전용 EC2 인스턴스 1대가 할당됩니다. 공유 nginx 라우터가 사용자별 인스턴스로 연결합니다.

  • 1 EC2 instance — t4g.large ARM64 (Ubuntu 24.04 또는 AL2023)
  • 1 EBS root volume — 사용자별 데이터 영구 보관 (Stop 시 그대로 유지)
  • 1 per-user IAM Instance Profile — Dashboard API가 RunInstances 직전 생성
  • 1 Nginx 라우팅 entry — {subdomain}.dev.{domain} → DynamoDB routing table → 5초 hot-reload
  • 3 DevEnv 포트 — code-server :8080, Frontend :3000, API :8000
  • Hibernation 지원 — RAM → 암호화 EBS, ~5초 resume

3. Local Governance Mode

EC2를 띄우지 않고 사용자가 본인 PC에서 claude를 직접 실행. Dashboard가 STS Issuer Lambda를 통해 1h chained-AssumeRole 자격증명을 발급.
