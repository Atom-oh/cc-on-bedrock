# Refactor

Improve code structure without changing behavior.

1. **Understand** - Identify the target, map callers/dependencies, confirm test coverage (suggest characterization tests if thin).
2. **Plan** - What changes, what doesn't, risk (low/medium/high).
3. **Change in small steps** - Run the relevant tests after each step; keep commits atomic.
4. **Verify** - Tests pass, behavior is unchanged, the goal is met.
